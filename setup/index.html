기본 설치

Windows 기준입니다. 관리자 권한이 필요한 PC라면 설치 전에 전산 담당자에게 먼저 확인하세요.

  1. GitHub 계정 만들기

    스킬은 대부분 GitHub에 올라와 있습니다. 링크를 열어 보거나 내 작업을 저장하려면 계정이 있어야 합니다. 회사 메일보다 개인 메일로 가입하는 편이 관리하기 쉽습니다.

    GitHub 가입

    로그인한 뒤 오른쪽 위에 내 프로필 사진이 보이면 끝입니다.

  2. Git 설치하고 내 이름 등록하기

    Git은 파일이 바뀐 기록을 남기고 GitHub와 주고받는 프로그램입니다. Codex와 Claude도 작업 폴더를 다룰 때 Git을 씁니다. 설치 화면의 선택지는 기본값 그대로 두고 Next를 눌러도 됩니다.

    Git for Windows 받기

    설치가 끝나면 시작 메뉴에서 PowerShell을 열고 아래 명령어를 한 줄씩 붙여 넣습니다. 따옴표 안은 내 이름과 GitHub에 가입한 메일로 바꿉니다.

    git --version
git config --global user.name "내 이름"
git config --global user.email "가입한메일@example.com"

    첫 줄에서 git version 2.xx처럼 버전이 나오면 설치된 것입니다. GitHub 로그인 창은 처음 올릴 때 브라우저로 뜹니다.

  3. Codex 설치하기

    Codex는 ChatGPT 데스크톱 앱 안에서 씁니다. 앱을 받아 ChatGPT 계정으로 로그인한 다음, 위쪽에서 Codex로 바꾸고 작업할 폴더를 고르면 됩니다.

    Codex 받기 공식 안내
    터미널에서 쓰고 싶다면

    PowerShell에 붙여 넣으면 터미널용 Codex가 설치됩니다. 설치 후 codex를 입력하면 시작합니다.

    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

    Codex 화면에서 폴더를 열고 "이 폴더에 뭐가 있어?"라고 물었을 때 답이 오면 됩니다.

  4. Claude 설치하기

    Claude 데스크톱 앱을 받아 로그인합니다. 폴더를 열고 파일을 고치는 작업은 앱의 Code 탭에서 하며, Pro 이상 요금제가 필요합니다.

    Claude 받기 공식 안내
    터미널에서 쓰고 싶다면

    PowerShell에 붙여 넣으면 Claude Code가 설치됩니다. 새 창을 열고 claude를 입력하면 브라우저 로그인으로 이어집니다.

    irm https://claude.ai/install.ps1 | iex

    Code 탭에서 폴더를 고르고 질문했을 때 답이 오면 됩니다.
