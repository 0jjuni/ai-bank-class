어느 쪽을 설치할까요

이미 유료로 쓰고 있는 쪽을 고르면 됩니다.

  • ChatGPT 유료 계정이 있다Codex
  • Claude Pro 이상 계정이 있다Claude
  • 둘 다 있다손에 익은 쪽
  • 둘 다 없다무료 ChatGPT 계정으로 Codex

ChatGPT 무료 요금제의 Codex는 가벼운 작업용입니다. 사용 한도가 공개돼 있지 않아 실습 중에 다 쓸 수도 있습니다.

설치하기

위에서 앱을 고르면 하나만 남습니다. Windows 기준이며 관리자 권한이 필요한 PC라면 전산 담당자에게 먼저 확인하세요.

Codex

  1. 앱 받기

    Codex는 ChatGPT 데스크톱 앱 안에 있습니다. 아래 버튼으로 앱을 받아 설치합니다.

    Codex 받기 요금제별 안내

  2. 로그인하고 Codex로 바꾸기

    ChatGPT 계정으로 로그인합니다. 왼쪽 위 ChatGPT 글자를 누르면 목록이 열리고 여기서 Codex를 고르면 됩니다.

  3. 작업할 폴더 고르기

    Codex 화면에서 작업할 폴더를 고릅니다.

    "이 폴더에 뭐가 있어?"라고 물었을 때 답이 오면 준비가 끝난 것입니다.

터미널에서 쓰고 싶다면 오늘은 안 씀

PowerShell에 붙여 넣으면 터미널용 Codex가 설치됩니다. 설치 후 codex를 입력하면 시작합니다.

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Claude

  1. 앱 받기

    Claude 데스크톱 앱을 받아 설치합니다. 폴더를 열고 파일을 고치는 작업은 앱의 Code 탭에서 합니다.

    Claude 받기 공식 안내

  2. 로그인하기

    시작 메뉴에서 Claude를 열고 Pro 이상 요금제 계정으로 로그인합니다.

  3. Code 탭 열기

    왼쪽 사이드바 맨 위 줄 오른쪽 끝의 </> 아이콘이 Code 탭입니다. 마우스를 올리면 이름이 보입니다.

    요금제를 올리라는 안내가 뜬다면 무료 계정이라는 뜻입니다. Code 탭은 Pro 이상에서만 열립니다.

  4. 작업할 폴더 고르기

    입력창 바로 아래 줄을 봅니다. 첫 번째 칸을 눌러 Local 아래 맨 위 항목을 고르고, 옆 칸에서 Open folder…를 눌러 작업할 폴더를 선택합니다.

    같은 줄의 권한 설정을 Manual로 두면 Claude가 파일을 고치거나 명령을 실행하기 전에 매번 물어봅니다. 처음 쓸 때는 Manual로 두는 편이 마음 편합니다.

    "이 폴더에 뭐가 있어?"라고 물었을 때 답이 오면 준비가 끝난 것입니다.

터미널에서 쓰고 싶다면 오늘은 안 씀

PowerShell에 붙여 넣으면 Claude Code가 설치됩니다. 새 창을 열고 claude를 입력하면 브라우저 로그인으로 이어집니다.

irm https://claude.ai/install.ps1 | iex

스킬 설치

스킬은 AI에게 일하는 방법을 적어 둔 폴더입니다. 오늘은 AI에게 설치를 맡기는 방법으로 배웁니다.

AI에게 설치를 맡기기

앱 입력창에 스킬의 GitHub 링크와 함께 아래처럼 보냅니다. 설치가 끝나면 앱을 껐다 켜야 목록에 보이는 경우가 있습니다.

이 GitHub 링크의 스킬을 설치하고, 사용 방법을 알려줘.
https://github.com/...

폴더에 직접 넣기 오늘은 안 씀

GitHub에서 받은 스킬 폴더를 아래 위치에 넣습니다. 폴더 안에 SKILL.md 파일이 있어야 합니다.

Codex
C:\Users\내이름\.codex\skills
Claude
C:\Users\내이름\.claude\skills

추천 스킬

    이 용도의 스킬은 아직 없습니다.

    스킬은 남이 만든 지시문입니다. 설치 전에 GitHub 페이지에서 만든 사람과 설명을 한 번 읽어 보고 업무 PC에서는 회사 보안 규정을 먼저 따르세요.

    ElevenLabs로 대본 읽히기

    글을 넣으면 사람 목소리로 읽어 주는 AI 음성 서비스입니다. 수업에서 본 커버드콜 설명 영상의 목소리도 ElevenLabs로 만들었습니다. 스킬이 아니라 웹사이트라서 따로 설치할 것은 없습니다.

    ElevenLabs 열기
    • 무료 요금제는 한 달에 10,000크레딧을 줍니다. 한 글자에 1크레딧이라 대략 1만 자를 읽힐 수 있습니다.
    • 무료 요금제에는 상업용 라이선스가 없습니다. 고객에게 나가는 자료에 쓰려면 유료 요금제가 필요합니다. 회사 규정도 먼저 확인하세요.
    • 같은 설정이어도 만들 때마다 조금씩 다르게 읽습니다. 몇 번 만들어 보고 마음에 드는 것을 고르세요.

    1. 가입하고 Text to Speech 열기

      elevenlabs.io에서 가입하고 로그인한 다음, 왼쪽 메뉴에서 Text to Speech를 누릅니다.

    2. 대본 붙여 넣기

      입력창에 대본을 붙여 넣습니다. 숫자와 기호는 "3%"보다 "3퍼센트"처럼 풀어 쓰면 덜 틀리게 읽습니다.

    3. 목소리와 모델 고르기

      왼쪽 아래에서 목소리를 고릅니다. 모델은 한국어를 지원하는 다국어 모델로 고르세요. 영어 전용 모델은 한국어를 어색하게 읽습니다.

    4. 만들고 내려받기

      Generate를 누르고 들어 본 뒤, 오른쪽 아래 내려받기 버튼으로 MP3 파일을 받습니다.

    5. 영상에 붙이기

      받은 MP3를 작업 폴더에 넣고 Codex나 Claude에게 이렇게 말하면 HyperFrames 영상에 붙일 수 있습니다.

      이 폴더의 음성 파일 길이에 맞춰 장면 시간을 맞추고, 영상에 음성을 넣어줘.
